# Arianna & Sebastian's Party Games

Party games on one phone: pass it around. No server, no accounts, works offline once installed.

Games: Imposter (+ Undercover mode) · Heads Up · Taboo · Wavelength · Fibbage · Most Likely To · Never Have I Ever · Truth or Dare · Would You Rather · Paranoia · Hot Potato · 5 Second Rule · Stop at 10 · Spin the Bottle · King's Cup

## Develop

```sh
npm install
npm run dev     # HTTPS dev server, also on your WLAN IP
npm test        # game logic tests
npm run build   # static site in dist/
```

**Testing on the phone:** `npm run dev` prints a `Network: https://192.168.x.x:5173` URL. Open it on the phone
(same WLAN) and accept the certificate warning. HTTPS is required for the Heads Up tilt sensor.

## Content

All cards and words live in `src/content/` as plain lists — edit freely.

## Deploy (GitHub Pages)

1. Create a GitHub repo and push this project to `main`.
2. Repo → Settings → Pages → Source: **GitHub Actions**.
3. Every push to `main` runs tests, builds and deploys (`.github/workflows/pages.yml`).

Install on the phone via "Add to Home Screen". After an update, the app picks up the new version on the second launch.
If you change `public/sw.js`, bump its `CACHE` version.

Icons are generated by `npm run icons`.
